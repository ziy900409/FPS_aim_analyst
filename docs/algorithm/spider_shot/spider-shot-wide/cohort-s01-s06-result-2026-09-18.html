00 / VERDICT

六個人之後，能不能選出最佳組合

仍然不能——但理由換了。

S01 時的理由是「只有一個人、順序只有一種」。現在滑鼠的位置已經反平衡（3 人排第一、3 人排最後），樣本變成六人，理由改為兩點：差異多半不超過同條件 run 之間的擺動，且唯一方向一致的訊號帶著一個無法解讀的註腳。

握法對比 B→C 在 5/5 受試者身上全部落在雜訊內，同時它對每一位受試者都與場內順序完全共線。

唯一方向一致的訊號

周邊命中時間中位數：DK/1-2-2 比 GPW1 慢，4/4 可比受試者皆然（+6.0 / +31.9 / +34.1 / +54.7 ms），其中 2/4 超出自身 run 波動。

但 GPW1 的握法只有 S01 被確認過。其餘 5 人的 A→B 可能是「換滑鼠」，也可能是「換滑鼠＋換握法」。在補上紀錄之前，這個訊號不能被稱為裝置效應。

可比性矩陣

比較性的單位是對比，不是 run。場中改設定沒有哪一邊是「漂移的那一邊」——兩個因子只是糾纏了，被毀掉的是跨越該變動的對比，而每個 run 仍然是它自己所記錄的那件事的有效量測。

03 / PROFILE

跨人 profile

原尺度值，每個 cell 為該受試者該條件 3 個 run 的合併值；括號內為 3 個 run 的數列。受試者之間的絕對水準差很大（命中時間中位數 516–701 ms），因此任何跨人彙總都必須以受試者為權重單位，不能把 trial 直接倒在一起。

各受試者的條件輪廓：命中時間中位數

每條折線是一位受試者，三個點是 A / B / C。線條互相交叉代表條件效果不具跨人一致性；線條的垂直位置差距就是受試者之間的能力差異。

04 / CONTRASTS

跨人配對對比

每一位受試者的配對都在自己身上完成（同 seed、逐筆驗證刺激一致），再以受試者為單位並列。灰帶是該受試者自己同條件 3 個 run 之間的全距——跨條件差值必須明顯跳出灰帶，才值得當成訊號而不是當天的起伏。

Δ 首發命中率（百分點）

灰帶 = ±（該受試者自身 run 間全距）。實心點 = 超出灰帶；空心點 = 未超過測量波動。

Δ 命中時間中位數（ms）

正值代表右側條件較慢。灰帶同左圖。A→B 四位可比受試者全部為正。

握法對比 5/5 落在雜訊內。B→C 的 Δ 首發率為 −7.8 到 +15.0 pp，而對應受試者自身的 run 間全距是 5.7 到 15.9 pp——沒有任何一位超出。再加上它對每個人都與場內順序共線，本批資料對握法沒有可供解讀的結論。
首發率與時間指向不同方向。在 4 位可比受試者中，DK/1-2-2 的首發命中率有 3 位較高（S01 +6.2、S03 +5.7、S05 +11.3 pp；S02 −10.0 pp），但命中時間 4/4 較慢。這與「較慢但首發較準」的取捨型態相容，然而 S02 在兩項上都較差，因此本批尚不足以支持該型態——它只是下一輪值得預先登錄的假設。

06 / MECHANISM

機制層：差異出在動作的哪一段

機制構念由 TypeScript 的 canonical 推導產生（analyze:spider-wide-mech），以 run_id + target_id 接進本表——2486/2486 逐筆對上，零未匹配。研究側不重算任何構念（C-D4）。 可採用與否由**這批資料實際產出的可算率**決定，不由分層決定：門檻 90% 是事前約定的慣例值，不是校準過的閾值。

Tier 1 在本 cohort 不可用，而原因不是 baseline 覆蓋率。 baselineInsufficient 全數為 false，detector 卻對 2486 筆中的 1696 筆回 timeout。 覆蓋率不等於乾淨度：KI-034 說的是 pre-stimulus 窗吃進前一次交戰，那會灌大 baseline SD、把偵測門檻頂高， 而覆蓋率旗標看不見這件事；1.2 秒的中心↔周邊週期保證了重疊。把 baseline_insufficient 讀成 KI-034 的全清訊號會判斷錯。因此本節不含反應時間與 movement time。

各受試者 × 條件的機制輪廓（中位數）

Δ 擊發邊際（ms）

正值＝右側條件在進靶後等更久才擊發。灰帶 = ±（該受試者自身 run 間全距）。

Δ 峰值角速度（deg/s）

負值＝右側條件甩得較慢。注意灰帶寬度——峰速的 run 間擺動本來就很大。

「較慢但首發較準」現在有了機制側的描述，但它的強度比方向一致性看起來弱。 在 A→B 的四位可比受試者中：峰值角速度 4/4 為負（−6.8／−25.2／−31.9／−56.0 deg/s，即 DK/1-2-2 甩得較慢）， 擊發邊際 3/4 為正（中位 +21.0 ms，即進靶後等更久才開火）。兩者方向都與「較慢、首發較準」相容。 但對照各自的 run 間波動：峰值角速度 0/4 超出、擊發邊際 2/4 超出（S03 +21.0 vs 帶寬 13.7、S05 +34.3 vs 11.6）。 峰速的方向一致性跨四人成立，量級卻每一位都落在自己的擺動之內。
不可據此宣稱裝置造成較慢的拉槍。三個理由並存： （1）A→B 的 GPW1 握法 5/6 未紀錄，這個對比可能是滑鼠＋握法； （2）峰速差沒有任何一位超出自身波動；（3）四人方向一致在樣本 4 上本身不構成統計證據。 正確的用法是把它當下一輪的預先登錄假設：DK/1-2-2 的峰速較低且擊發較晚，是否在反平衡握法與足夠人數下重現。
07 / FINDINGS

S01 六項 Finding 的再檢視

S01 報告的主要產出是四個量測問題與兩個能力缺口。以下逐項對照 cohort 結果，標出影響是擴大、持平，還是只有在 cohort 才看得到的新問題。

F02 · 殘留擊發證據等級大幅提升

不再是候選，而是有簽名的量測假象

cohort 共 6 筆，橫跨 5 / 6 位受試者。六筆全部同時滿足兩個條件：開火落在目標出現後 60–140 ms，且首發角誤差 47.5–51.8°。本 drill 的中心↔周邊角距是 47.7–51.9°（seed 57001 對所有人相同），也就是說誤差幾乎精確等於「準心還停在前一個中心目標上」。

六筆全部被判為首發失手。量級仍小（0.25% 的呈現，首發率影響 ≤ 0.7 pp），但它每次都製造一次假失手，且落點在條件之間不均。S01 時只能說「需要一條護欄」；現在可以寫成明確規則：first_fire < 150 ms 且 offset ≈ D_deg。門檻仍必須在看資料前鎖定。

F02 的簽名：首發時間 × 首發角誤差

2421 個首發（縱軸為對數刻度）。左上角那一叢孤立點就是殘留擊發——它們與主群體之間隔著超過一個數量級的角誤差，沒有任何連續過渡。順帶驗證了抽取正確：命中（青）與失手（琥珀）的分界恰好落在 1.0°，也就是 2.0° 目標的角半徑。

F06 · run 間雜訊尺度大幅擴大

雜訊尺度從 3 個 cell 變成 17 個，而且比差異大

同條件 3 個 run 之間的首發率全距：中位數 8.5 pp、最大 15.9 pp、最小 3.3 pp。對照之下，跨條件的 Δ 首發率為 −10.0 到 +15.0 pp。

結果：9 個「受試者 × 對比」（A→B 與 B→C）之中，只有 2 個超出自身雜訊帶，而且方向相反（S02 −10.0 pp、S05 +11.3 pp，都在 A→B）。S01 的結論不但成立，且被六倍資料強化。

F03 · 回中心佔比擴大

現象普遍，但 77% 是 S01 特例

A→B 的週期差之中，回中心所佔比例為 34% / 50% / 57% / 77% / 78%（五位受試者），B→C 為 20–59%。所以 S01 的「77%」不是通例，但「相當大一部分的速率差異落在周邊指標完全看不到的地方」在每一位受試者身上都成立。

建議不變：把「回中心時間」納入資料契約。它是直接讀數，不需要新的構念定義。

F01 · 錄製尾巴持平

仍然只有 1/51，單發影響不變

整個 cohort 只有 S01 / GPW1 / rep1 帶錄製尾巴（5062.5 ms）。以原始錄製長度當 rate 分母，該 run 會從 45.00 掉到 39.67 hits/min（−11.8%）。頻率沒有上升，但 51 個 run 出現一次代表它會持續發生，protocol 邊界的修剪必須留著。

F04 · timeout 護欄確認，逼近度上升

2442 次呈現、0 次 timeout

最長觀測時間 2249.1 ms（S01 時只到 1700.6 ms），僅 3 次呈現超過 2000 ms。2500 ms 期限仍未被觸發過，δF 閘在這個難度下無法區分任何條件；但邊際已經不再寬裕，較慢的受試者進來後它可能開始咬到。

F05 · 機制層已解除一半

Tier 0 已可算，Tier 1 在這批資料上不可用

本頁定稿後已建立 TS 抽取層（analyze:spider-wide-mech），實測 2486 次呈現的可算率依層別分裂：

Tier 0（不經 detector）99.1–100% —— peak／entry ω、煞停保留率、擊發邊際、drop、micro-adjust、首發角誤差。首批真實值：煞停保留率中位數 0.072（進靶時只剩峰速的 7%）、擊發邊際中位數 +73 ms，其中 6.9% 的首發早於進靶。

Tier 1（reaction／movement time）僅 31.8%，不可用於本 cohort。關鍵在於原因不是 baseline 覆蓋率——baselineInsufficient 全數為 false，detector 卻對 2486 筆中的 1696 筆回 timeout。覆蓋率不等於乾淨度：KI-034 講的是 pre-stimulus 窗吃進前一次交戰，那會灌大 baseline SD、把偵測門檻頂高，而覆蓋率旗標看不見這件事；1.2 秒的週期保證了重疊。

因此本頁浮現的機制問題（DK/1-2-2 較慢 4/4 但首發率多半較高 3/4）現在有工具可查，但只能用 Tier 0 的煞停與擊發時機去查，不能用反應時間。機制層數值已併入 §06：峰值角速度在 4/4 可比受試者身上較低、擊發邊際 3/4 較長，但只有擊發邊際有 2/4 超出自身 run 波動。

N1 · 只有 cohort 看得到新

順序反平衡只做對了一半

GPW1 位置 3:3 反平衡（已解除 S01 的裝置—時間共線），但 1-2-2 在 5/5 受試者身上都排在 1-3-1 之前。握法對比對每一位受試者都與場內順序完全共線。

N2 · 只有 cohort 看得到新

GPW1 的握法 5/6 未紀錄

只有 S01 被確認為 1-2-2。若其餘受試者在 GPW1 上用的不是 1-2-2，A→B 就不是滑鼠對比而是滑鼠＋握法。這是紀錄缺口而非資料問題，且它正好牽制本批唯一方向一致的訊號。

N3 · 只有 cohort 看得到新

場中改設定，以及它應該由誰承擔

S04 在場中把感度從 1.1 改為 1.0。處置方式從「標記漂移的 run」改為「標記跨越變動的對比」——因為沒有哪一邊是漂移的那一邊。結果是 S04 保住了 B→C，只失去 A→B 與 A→C；若按 run 排除，會連 3 個乾淨的 GPW1 run 一起丟掉。
