00 / VERDICT

先回答：這批資料能不能選出最佳組合

不能。證據不足以確認最佳組合。

這是 Track P 的預期出口，不是失敗。三個條件的首發命中率相差 6.2 個百分點，但同一條件三個 run 之間本身就擺動 6.1–12.2 個百分點；時間中位數相差 34–51 ms，而 C 條件自己的 run 之間就差 103 ms。差異沒有大到超過測量本身的擺動。

唯一超出同條件波動的是 A→B 的 hits/min（+2.67，A 的 run 間全距 0.0、B 為 1.0）。但它正好是相隔 68 分鐘的那一組對比，而且其中 77% 來自「回中心」那半個週期——不是周邊拉槍。

管線狀態：可用，且已抓到問題

9 個 run 全數通過硬閘、417 次呈現全部成功抽取、配對前綴 129/129 逐筆刺激驗證一致、0 筆 timeout、僅 6 筆行政右截。

過程中抓到 4 個會改變結論的量測問題（§07），其中 2 個若不處理會放大條件差異。機制層 7 個指標尚不可算，須等 TS canonical 抽取層。

07 / PIPELINE

管線試跑抓到什麼

這才是本次試跑的主要產出。下列四個問題若不處理，都會改變條件之間的比較結果；後兩項是能力缺口。

Finding 01 · 會放大差異

錄製尾巴若不修剪，滑鼠差距被灌水 66%

A rep1 的錄製長度 68062.5 ms，其餘 8 個 run 皆 63000.0 ms；多出的 5062.5 ms 全為零位移，起點正好在其他 run 的結束 tick。以原始錄製長度當 rate 分母，B−A 會從 +2.67 變成 +4.44 hits/min。

處置：已採用 protocol 邊界（first visible + 60000 ms），並記 TRIM_POST_TASK。抽取層不得以「最後一槍／最後一個 visible／最後一個非零 tick」當 active_end。

Finding 02 · 會製造假失手

首發可能是上一次交戰的殘留擊發

B rep3 第 9 次呈現：目標出現後 80 ms 就有一發，角誤差 48.36°，判為 miss。80 ms 低於任何合理的視覺反應時間，該發實際上是對準上一個中心目標的殘留扣扳機，卻被系統歸屬到新目標，讓 B 平白吃掉一次首發失手。

處置：需要一條事前登錄的最小延遲護欄。本批以 ≥150 ms 試算，只影響 B（91.72% → 92.36%），不改變任何結論；但在 n 更小或殘留更多的 cohort 上它會。門檻必須在看資料前鎖定。

Finding 03 · 指標涵蓋缺口

rate 的差異大半落在周邊指標看不到的地方

A→B 的週期縮短 74.1 ms 中，回中心佔 −57.0 ms（77%）、周邊拉槍只佔 −17.1 ms。目前整組指標（首發率、time-to-hit、機制層）全部只描述周邊那一半，因此無法解釋自己最大的那個差異。

建議：把「回中心時間」（中心 visible → 下一個 visible）加進資料契約，作為與周邊指標並列的獨立欄位。它是直接讀數，不需要新的構念定義。

Finding 04 · 指標失效（非故障）

timeout risk 在本任務上沒有資訊

417 次呈現、0 次 timeout。2500 ms 的 peek 期限從未逼近（最長觀測 1700.6 ms）。它在決策規則中被列為四個主要指標之一（δF 閘），但在這個難度下恆為 0，無法區分任何條件。

建議：正式研究凍結門檻前重新評估 δF 是否有意義，或改用尾端時間指標承擔同一角色。好消息是：沒有 timeout 也意味著沒有天花板效應，p90 三條件皆可估。

Finding 05 · 能力缺口

機制層 7 個指標全部不可算

reaction、movement time、peak／entry ω、煞停保留率、擊發邊際、overshoot／drop、疑似 repositioning —— 全部依賴 canonical 的 onset／entry／角速度推導，那些定義住在 src/metrics/*.ts。在 Python 端重寫等於建立第二套定義（C-D4），因此本次標為不可算而非近似。

唯一可得的機制相鄰讀數是 fire 事件自帶的 offsetDeg（首發角誤差），已列入 §03。要補齊機制層，需要一個重用既有 canonical derivation 的 TS 抽取層。

Finding 06 · 設計缺口

雜訊尺度只有 3 個 run 可估，且 C 內部並非穩定狀態

本頁用同條件 3 個 run 的全距當雜訊尺度，這是探索性 run 波動，不是 MDC——重測誤差需要獨立的跨日重測資料。更麻煩的是 C 的三個 run 單向改善（hits/min 42→45→46、右鍵 34→28→17），它們不是同一狀態的三次抽樣，因此 C 的全距同時混進了適應趨勢。

影響：C 的任何彙總值代表性存疑，而它又同時是雜訊尺度最大的條件。這正是最終 workflow 要求獨立熟悉日與跨日重測的原因。
