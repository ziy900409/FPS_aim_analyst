STEP 0

啟動畫面 — 兩個清楚選項

新

現況是四顆按鈕平鋪(實驗 session / 解析度 protocol / BR protocol / Session Plan),語意不對等卻並列。 本提案收斂成兩個入口,語意上一次分岔清楚:「這是要測選手」還是「這是研究員自己在用」。

launch-screen.html
與現況差異：現況「實驗 session」「Session Plan」兩顆按鈕語意其實都是「選手測試」的不同版本，容易混淆； 「解析度 protocol」「BR protocol」是研究/校準工具，本提案把它們收進研究員模式的子選單（見 STEP 4），不佔用主畫面版面。
STEP 1

Session Plan — 可勾選 + 拖曳排序 + 全域休息秒數

新 偏離 FR-G9②

現況家族順序由 buildFamilyOrder()（WP-41）自動決定，trial 數/休息秒數只能選具名 preset。 本提案讓操作者自己拖曳排序、自己輸入休息秒數——這是本次對話明確拍板的取捨（見 README §2.3c/d），不是既有紀律的延伸。

STEP 5

單一 Drill 調整 — 既有 Controls 面板,改為獨立畫面

既有 Controls.ts 元件不變,只改掛載時機

現況這個下拉選單面板是常駐在畫面下方的 floating bar；本提案讓它只在「研究員模式 → 單一 Drill 調整」被點選後才出現， 且跳過資格閘/session setup 表單（研究模式要快速迭代，不該被受試者流程卡住）。本階段不新增任何逐參數輸入欄位——D_deg、holdDurationMs 等數值仍是改 config 原始碼。
