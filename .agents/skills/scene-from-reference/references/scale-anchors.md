# 尺度錨定階梯 — 沒有量測,只有錨定

> P1 載入。**照片與影片給不出公制尺度**;任何「我量出來是 X 公尺」都是幻覺。
> 唯一合法做法:拿畫面裡已知尺寸的東西當尺,推出級距,並誠實標信心。

## 單位

canonical unit `u`。本 repo 一律 `displayScale: 1`,`1u` ≈ 1 公尺量級
(眼高 1.6u、掩體高 3u、房高 4u 都符合此量級)。

## 錨定階梯(由可靠到不可靠,取最上面能用的那層)

| 層 | 錨 | 已知值 | 信心 |
|---|---|---|---|
| A1 | **玩家眼高** | `1.6u`(全場景固定) | **high** — 第一人稱畫面永遠有這個錨 |
| A2 | **既有場景數值** | 房高 `4u`、掩體 `3u`、走廊半寬 `1u` | high — 直接沿用而非重新估 |
| A3 | **視野角** | `fovDeg: 75` | med — 可由物體佔畫面比例反推角尺寸 |
| A4 | 常見建築常識 | 門 ≈ 2.1u、階高 ≈ 0.18u、車高 ≈ 1.5u | med |
| A5 | 畫面比例目測 | 「大約是玩家的兩倍高」 | **low** — 只能給級距,不能給單值 |

## 信心標記規則

| confidence | 何時用 | 產出形式 |
|---|---|---|
| `high` | 錨 A1/A2,或該值其實由 drill 規格決定 | 單值 |
| `med` | 錨 A3/A4,或多幀交叉一致 | 單值 + ±範圍 |
| `low` | 錨 A5,或只有一幀、透視嚴重 | **只給級距**,並在 `unknowns` 留一筆 |

格式:`{ value_u: 3, anchor: "A1 眼高 1.6u × 約 1.9 倍", confidence: "med" }`

## 反推的三個實用套路

1. **眼高比對**:畫面中掩體上緣與地平線(≈ 眼高 1.6u)的相對位置 →
   齊平 = 1.6u(head-glitch 成立);高一個頭 ≈ 1.9–2.1u;高一倍 ≈ 3u+。
2. **距離級距**:目標在畫面中的角尺寸 + `fovDeg 75` → 角尺寸級距 → 距離級距。
   **但最終距離由 drill 的 `distance` 決定**,這裡只用來檢查場景容不容得下。
3. **走廊寬度**:玩家橫移可及範圍 → `playerCorridor.halfWidthU`。
   現行值只有 `1` 與 `2`;優先沿用,別發明 `1.37`。

## 紅線

- **禁止**由畫面比例還原整張平面圖(踩 R1)。錨定只用在「單個掩體的高/寬級距」這種局部量。
- 交戰距離、目標尺寸、目標速度**不由畫面決定**——由 drill 規格反推。
  畫面上的距離只回答一個問題:「`room_size_proposal` 夠不夠深?」
- 任何 `confidence: low` 的值,必須在 `unknowns` 有對應條目,說明它會擋住哪個 Task。
